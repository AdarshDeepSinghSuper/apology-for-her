# A little apology ♡

A tiny, mobile friendly apology page made with plain HTML, CSS, and JavaScript. It is ready to publish with GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository and add these four files to its root: `index.html`, `style.css`, `script.js`, and `README.md`.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Once GitHub finishes publishing, open the Pages URL shown in Settings and send it to her.

The WhatsApp link opens a chat with the number configured in `script.js` and fills in an apology message. Check the number and personalize the message before publishing.
